# v14 vs v11 on Berakhot — what moved, and what the consensus judges say

**Self-contained.** A fresh session executes this with no other context.
Read [`FRAMEWORK.md`](../../FRAMEWORK.md) first, then this.

## The claim to test / the problem

v14 was adopted on 2026-11-08 from a full-Yevamot comparison
([finding](../../docs/findings/2026-11-08-v14-vs-v11-yevamot.md)). Berakhot has a v11 run
(branch `septimus/shas-berakhot`) and **no expert list**, so there is no recall: only what
the two versions disagree on, and what the consensus judges say about it under the current
`docs/STORY_RULES.md`. Everything here is **indicated** at best — the judges are not Jeff.

## Method

1. Inputs from `origin/septimus/shas-berakhot` (left uncommitted): `results/sefaria/berakhot.json`,
   `results/triage/berakhot.json`, `results/v11/berakhot/berakhot_v11.json`.
2. v14 twice with the committed runner → `results/v14/berakhot/run{1,2}.json`. 0 Stage 1 calls;
   triage cache SHA-1 unchanged.
3. `scripts/compare_v14_v11_berakhot.py`: a passage moved only if kept in every run of one
   version and none of the other. No model calls.
4. `scripts/judge_detector_spans.py`: the union of every span any run proposed, merged by
   segment overlap, through the same judge prompt and `ask()` as
   `scripts/judge_labelled_spans.py`. Gemini arm via API; Claude arm via subagents
   (`judge_via_subagents.py` machinery). Failed/invalid answers counted, never scored.

## How you know it worked

Both v14 runs: 0 Stage 2 errors, 0 twin failures. Every judge unit has an outcome from each arm.

## Guardrails

No change to the runner, the detector files, STATUS.md, `evaluate_golden.py`. Gemini judge
cap $10; stop and ask over it. No Claude API spend.

## When done

Write the finding to `docs/findings/<date>-<slug>.md`, add an `## Outcome` section
below, and `git mv` this file to `work/done/`. **Never delete it.**

## Outcome

Done 2026-11-09. Finding: [`docs/findings/2026-11-08-v14-vs-v11-berakhot.md`](../../docs/findings/2026-11-08-v14-vs-v11-berakhot.md).

- Kept proposals: v11 201; v14 189 and 187 (two clean runs, ~$2.2 each, 0 Stage 1 calls,
  triage cache unchanged).
- 21 passages moved (3 v14-only, 18 v11-only). By the register most v11-only ones are
  habits, bare reports and Q&A that the October rulings rule out.

  v14 slightly more than with v11 (Gemini 84.8% vs 83.9%, Claude 73.2% vs 67.9%, kept-vs-not).
  On the 20 moved units both judges side with v14 on 14 and with v11 on 1; 5 split.

  planned v15 filter.
- **Why it is only indicated:** there is no expert list for Berakhot, the judges are not
  Jeff, and there is one v11 run. The judge prompt still carries R-C7 shape 2, which Jeff

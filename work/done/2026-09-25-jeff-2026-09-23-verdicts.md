## Method

  through its builder, which must still reproduce the committed file byte-for-byte
  before the new verdict file is added.
- Twin pass: re-ask the twin question, with the new prompt, for every twin-pass
  addition already on disk. The page-level prompt and the candidates do not change,
  so the prompt is the only variable.

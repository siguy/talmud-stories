## Defects found during the run (measured; none changes the site)

1. **`run_shas.py --tractates X` rewrites `status.json` down to X.** The other tractates' state is rebuilt from disk
   by the next full run, at no cost. Still to fix: merge into the existing file.
2. **G5's density range widens as tractates join.** It compares a tractate with every other run tractate, so
   Keritot (0.30) unflagged Zevachim (0.54). The reading list uses the range fixed at first firing. Still to fix:
   pin G5 the same way.
3. **The Gemini judge has no retry on 429.** Run several at once and they exceed 3M input tokens a minute; 182
   calls failed that way. They were re-run one tractate at a time (`--parallel 1`). Still to fix: put the judge
   behind the runner's retry wrapper.
4. **The Gemini judge isn't metered.** Hence the estimate above.
5. **The judge resume re-asked only `failed` rows**, not `invalid` ones, so G6's "one resume" could not clear them.
   Fixed: it now re-asks both.
6. **A 2-page triage cache from the smoke test** made the driver treat Taanit's triage as done (it checks that the
   output exists). G2 caught it as red. The `--retry-failed` run resumed the remaining 57 pages.
7. **Subagents launched from one worktree cannot write into another.** A hook refused 7 of the 8 judge groups;
   their answers were saved to a scratchpad and copied in, with counts checked against the keys. Launch them from
   the worktree they write to.

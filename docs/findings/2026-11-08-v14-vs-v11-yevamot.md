## What this says

1. **Recall does not separate them.** The tie found on the slice holds on 242 pages.
   (**measured**, n = 3 and 2)
2. **v14's October lines do what they were written for, on passages they were not written
   from.** Five of the eight v11-only proposals are the shapes Jeff ruled out in October:
   a habit (39b:8), a bare report (102b:0), a transmission (57a:12), a case before a rabbi
   (65b:12, 122a). (**indicated**)
3. **But v14 loosens R-C2.** Five of the eight v14-only proposals are scholarly exchanges
   that Jeff's 2026-10-07 line calls not a story (41a, 42b:3, 42b:8, 110b, plus 42b:9–10
   contested) — although v14's prompt carries that line ("An ordinary scholarly exchange
   is NOT conflict"). Two v14 borderline lines that v11 lacks fit these passages better:
   *"A sage teaching or learning… it is still mainly speech → LOW_CONFIDENCE"* (R-C2,
   50a:10) and *"Mainly dialogue but with some real events → LOW_CONFIDENCE"* (walking into
   the market, leaving the study hall). **suspected**: no arm removes either sentence alone.
4. **v14's R-S1 edit does not hold.** David is kept 2 of 2, and 60b:10–11 is biblical
   material v11 never proposed. The slice's suggested fix — adding biblical peoples
   (Gibeonites, Midianites…) to `filter_biblical_actor_stories()` — would catch David; it
   would not catch 60b, which names no actor at all: it is the Gemara explaining a verse.
5. **On the register's own terms the two versions are close:** roughly six passages where
   v14 is right and v11 wrong, and eight the other way. No ground truth for precision
   exists here (the 2005 list is not comprehensive), so all of these are our reading.

## The confound

The v11 arm was not run today. Its three runs date from 2026-09 and their `run_meta` lacks
`detector_module` and `git_rev`. Since then v11's own code has changed (PR #69: 4c boundary
check, sorted stories, failed calls flagged; PR #71: cross-page stories kept whole, the
scope filter matches whole names, 429s retried). So a difference between the arms can come
from **the October wording, those code fixes, or day-to-day drift** (Lessons 11 and 22).
77a:0 is probably the code fix. The slice had a clean same-day v11 pair, and on the passages
that overlap (65b:12, 78b:9, 78b:13–20, 105b:14–15) this run agrees with it. That is why
the readings above are given as **indicated**, not measured. Running v11 twice today
(~$3.7) would settle it.

## Recommendation (as first written — superseded by § Correction)

- **Do not switch the runner to v14.** It gains no recall, and it adds R-S1 and R-C2
  errors that offset the R-C0/R-C5 errors it removes.
- **A v15 worth measuring:** v14 + the biblical-peoples list in
  `filter_biblical_actor_stories()` (count what it touches on disk first, Lesson 27) + the
  "a sage teaching or learning → LOW_CONFIDENCE" line limited to passages with a real
  event beyond the teaching. Read
  41a, 42b, 110b, 60b, 78b:13–20 and 105b by name.
- **For Jeff:** 57a:6 joins 78b:9 under `jeff:question-and-answer`. Both are on his list,
  and both are a question to a sage with nothing else happening.

## Correction (same day, after review with Simon) — v14 is adopted

The first recommendation weighed the two error lists as if they were equal, and they are
not:

- **What v14 removes is Jeff's own October rulings** (R-C0 2026-10-25, R-C3/R-C5). His
  recent rulings outrank the 2005 list and our older prompt wording. v11 does not carry
  them, so it breaks them every time it runs.
- **Most of what v14 adds is borderline** (`LOW_CONFIDENCE`), and borderline passages stay
  in the catalogue for review. The R-C2 additions cost review time, not lost stories.
- **The R-S1 error is not v14's alone.** v11 keeps David in 1 of 3 runs.
- **Fresh v11 runs would not change the decision.** PRs #69/#71 changed boundaries,
  ordering, failure flags and the scope filter, not the classification wording. The slice
  had a same-day v11 pair, and it agrees with this run on every passage the two share. The
  "~$3.7 would settle it" line above is withdrawn.

**So: `scripts/run_new_tractate.py` imports v14** (pinned by
`tests/test_new_detector_code_is_v11_code.py::test_the_runner_imports_v14`). Its default
output path still reads `results/v11/<tractate>/…`. `run_meta.detector_module` is what
says which detector ran.

**The biblical error can be fixed after the fact, with no API calls.**
`filter_biblical_actor_stories()` (Stage 4j) reads only the actor list that Stage 2 already
wrote into each story (`criteria.identifiable_characters.evidence`). It missed all three
cases here because the actors are groups and places, not the names on its list: *"King
David, God, the Jewish People"*, *"the daughters of Midian, the High Priest"*, *"the
inhabitants of Jabesh-gilead"*. If the list grows (biblical peoples and places), and
generic actors (God, the Jewish People, Israel) stop counting as non-biblical, the filter
catches all three. It can then be re-applied to every run on disk, so Berakhot and Yevamot
need no re-run. The change has to be a new version (v15), because v14 is now a ship point.
Count what it touches on every tractate first (Lesson 27). "God" and "Israel" also appear
in rabbinic stories, so a story whose *other* actors are rabbis must stay in.
